# 账户中台原型

**[打开原型界面](https://skyzhou2026.github.io/zhongtai/)**（点这个链接直接进可点的页面，不是看代码）

账户中台 V1.0（商户登录互通）交互原型。只演示跨应用登录和免登，不包含角色/权限。

## 打开方式

在线打开：https://skyzhou2026.github.io/zhongtai/

或下载后用浏览器打开 `index.html`。

左侧切场景，中间是模拟浏览器（看地址栏域名变化）。右上角可切 **正常 / 慢**。

演示账号：`merchant@best.com` / `Pass1234`

## 场景

1. 初始进入 BPS（无任何登录态）
2. 进入 BPS（中台已有登录态）
3. 输入账户密码登录 BPS
4. 已登录 BPS，打开 ADS
5. 退出 BPS
